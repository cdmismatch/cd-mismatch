# cd-mismatch
The code and data of studying control and data plane mismatch in interdomain routing.
Title: A Comparative Approach for Studying Control and Data Plane Mismatch in Interdomain Routing
Abstract: In inter-domain routing, packets do not always follow the Autonomous System (AS)-level path specified by the BGP routing protocol, a phenomenon known as control-plane and data-plane (CD) mismatch. We conduct a comprehensive analysis of CD mismatch using Internet-wide CD paths collected from 128 pairs of vantage points over more than five years. We show that IP-to-AS mapping algorithms may exert a significant impact on the analysis, which in turn inspires a novel method to assess their general accuracy and subtle impact in depth. With this method, we can not only identify the advantages and disadvantages of 8 state-of-the-art mapping algorithms (including their combinations), but also design a better one, which we call LTC. Compared with the top-performing existing algorithm (i.e., BdrmapIt+IXP), LTC can correct over 64\% of its mapping errors and effectively eliminate CD pairs misinterpreted as mismatches due to those errors. Using LTC, we estimate the Internet-wide CD mismatch ratio to be around 5.9\%--8.7\%, a significantly more accurate and confident range than previous studies have reported. We also explore how CD mismatches can be used to effectively identify complex routing security issues that have traditionally been challenging to detect.
Status / Availability Statement: The full source code (including the LTC implementation) and the processed datasets described in this paper are currently being documented and organized for public release. All resources will be made permanently available in this repository immediately upon the formal acceptance of the paper.
